# Contributing

Issues and pull requests are welcome.

1. Open an issue describing the problem or proposed behavior.
2. Create a focused branch and include tests for behavior changes.
3. Follow WordPress Coding Standards and escape output at the point of rendering.
4. Never add telemetry fields that can identify a store, shopper, order or address.
5. Update `CHANGELOG.md` for user-visible changes.

Use responsible disclosure through `SECURITY.md` for vulnerabilities rather than a public issue.
